## 🎯 핵심 기능

### 1. 자동 보안 (prevent-leak.md)
- 모든 작업 전 민감 정보 자동 차단
- API 키, 비밀번호, DB 연결 문자열 마스킹
- Git 커밋 전 자동 스캔

### 2. 자동 백업 (auto-backup.md)
- 파일 수정 전 Git stash 자동 생성
- 복원 명령어 자동 제공
- 데이터 손실 0%

### 3. 영구 기억 (obsidian-*)
- 모든 대화 자동 저장
- 결정 사항 영구 보존
- 트러블슈팅 히스토리 완벽 추적

### 4. 토큰 최적화 (token-efficient-architecture.md)
- 인덱스 기반 검색 (99% 절약)
- 계층적 로딩 (필요한 것만)
- 요약 우선 제공

### 5. 스마트 태깅 (obsidian-tagging-rules.md)
- 3단계 자동 분류
- 양방향 링크 자동 생성
- AI 친화적 구조

## 💡 사용 시나리오

### 시나리오 1: 새 프로젝트 시작
```markdown
1. 프로젝트 폴더 생성
2. Claude 시작
3. 옵시디언 자동 초기화
4. 작업 시작 - 모든 것이 자동으로 기록됨
```

### 시나리오 2: 이전 작업 기억
```markdown
사용자: "지난주에 뭐 했었지?"
Claude:
  → 옵시디언 인덱스 검색 (500 토큰)
  → 지난주 작업 4개 발견
  → 요약 제공 (300 토큰)
  **총 800 토큰** (vs 전체 로드 50,000 토큰)
```

### 시나리오 3: 트러블슈팅 해결
```markdown
1. 에러 발생
2. error-analysis Skill 자동 실행
3. 문제 해결
4. 트러블슈팅 문서 자동 저장
5. 다음에 같은 문제 발생 시 즉시 검색 가능
```
