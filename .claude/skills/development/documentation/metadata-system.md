# 메타데이터 기반 지식 분류 시스템

**카테고리**: Development - Documentation
**목적**: 메타데이터로 모든 문서를 자동 연결하고 분류

## 🎯 핵심 개념

### 왜 메타데이터가 중요한가?
```markdown
# ❌ 나쁜 예: 태그만 사용
#나라똔 #인증 #트러블슈팅

→ 검색은 되지만:
  - 어떤 기능의 인증인지 모름
  - 어느 버전에서 발생했는지 모름
  - 관련 문서가 무엇인지 모름
  - 우선순위를 모름

# ✅ 좋은 예: 메타데이터 + 태그
---
프로젝트: 나라똔
기능모듈: 관리자/인증
기능명칭: JWT 토큰 검증
버전: v1.2.0
관련기능: [심사관관리, 정책뉴스관리]
선행작업: [[RBAC아키텍처]]
우선순위: High
---

→ 즉시 알 수 있음:
  - 프로젝트: 나라똔
  - 모듈: 관리자 > 인증
  - 기능: JWT 토큰 검증
  - 관련: 심사관관리, 정책뉴스관리
  - 우선순위: High
```

## 📊 메타데이터 체계

### Level 1: 프로젝트 식별 (필수)
```yaml
프로젝트: 나라똔
프로젝트코드: NRDN
프로젝트버전: v1.2.0
저장소: https://github.com/user/naraddon
```

**Dataview 쿼리**:
```dataview
TABLE 프로젝트버전, 카테고리
FROM "Projects"
WHERE 프로젝트 = "나라똔"
SORT 날짜 DESC
```

### Level 2: 기능 분류 (필수)
```yaml
기능모듈: 관리자/인증
기능명칭: JWT 토큰 검증
기능범주: [인증, 보안, 세션관리]
기능상태: 개발완료
```

**계층 구조**:
```
관리자/
├── 인증/
│   ├── JWT 토큰 검증
│   ├── OAuth 로그인
│   └── 세션 관리
├── 심사관관리/
│   ├── 이미지 업로드
│   └── 정보 수정
└── 정책뉴스관리/
    ├── 업로드
    └── 검색
```

### Level 3: 문서 관계 (핵심!)
```yaml
선행작업: [RBAC아키텍처, 사용자스키마]
후속작업: [관리자세션캐싱, 권한세밀화]
관련기능: [심사관관리, 정책뉴스관리]
참조문서: [NextAuth공식문서, MongoDB인덱싱가이드]
영향범위: [관리자전체, API인증]
```

**자동 연결**:
