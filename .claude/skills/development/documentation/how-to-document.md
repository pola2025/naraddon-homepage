# 옵시디언 형식 문서화 가이드

**카테고리**: Development - Documentation
**목적**: 성공적인 작업을 옵시디언 형식으로 완벽하게 문서화

## 🎯 핵심 원칙

### 문서화의 목적
```markdown
1. **AI가 즉시 이해** - Claude가 파일명/메타데이터만 봐도 내용 파악
2. **빠른 검색** - 태그/메타데이터로 1초 내 검색
3. **지식 연결** - 양방향 링크로 관련 문서 자동 연결
4. **컨텍스트 보존** - 왜 이렇게 했는지 배경까지 기록
```

## 📋 문서 구조 템플릿

### 1. YAML Front Matter (필수)
```yaml
---
title: {구체적이고 직관적인 제목}
날짜: {YYYY-MM-DD}
프로젝트: {프로젝트명}
카테고리: {카테고리}
태그:
  - 프로젝트/{프로젝트명}
  - 기능/{도메인}/{상세기능}
  - 작업유형/{작업타입}
  - 상태/{상태}
---
```

**실전 예시** (대화기록):
```yaml
---
title: Claude Skills 시스템 구축 대화
날짜: 2025-10-19
프로젝트: 나라똔
카테고리: 대화기록
대화유형: 시스템설계
참여자: [사용자, Claude]
소요시간: 약 2시간
주요성과: Skills 자동화, 슈퍼메모리, 토큰최적화
tags:
  - 프로젝트/나라똔
  - 작업유형/시스템설계
  - 기술/Obsidian
  - 기술/Claude
  - 자동화
  - 문서화
  - 토큰최적화
---
```

### 2. 해시태그 라인 (검색 최적화)
```markdown
#나라똔 #시스템설계 #자동화 #Obsidian #슈퍼메모리 #토큰최적화
```

**규칙**:
- Front Matter 태그를 간결한 해시태그로 재표현
- AI가 빠르게 스캔할 수 있도록 한 줄에 모두

### 3. 제목 (# H1)
```markdown
# {문서의 핵심 내용을 한 문장으로}
```

**좋은 예**:
- ✅ `# Claude Skills 시스템 구축 대화`
- ✅ `# 관리자인증 - 403에러 - JWT콜백미조회`

**나쁜 예**:
- ❌ `# 작업 내용`
- ❌ `# 문서`

### 4. 개요 섹션 (## 📅)
```markdown
## 📅 대화 개요
- **시작**: {YYYY-MM-DD HH:MM}
- **종료**: {YYYY-MM-DD HH:MM}
- **참여자**: {참여자 목록}
- **목적**: {한 문장 요약}
```

**왜 필요한가?**
- AI가 가장 먼저 읽는 섹션
- 문서 전체 맥락을 30초 내 파악

### 5. 흐름/과정 섹션 (## 🎯)
```markdown
## 🎯 대화 흐름 요약

### 1단계: {단계명}
**사용자 요청**: "{실제 요청 내용}"

**Claude 응답**:
- {핵심 응답 1}
- {핵심 응답 2}

**결과**:
```코드 또는 구조```

### 2단계: {다음 단계}
...
```

**작성 팁**:
- 시간순으로 작성
- 각 단계마다 요청-응답-결과 구조
- 코드/구조는 코드블럭으로

### 6. 결정사항 섹션 (## 💡)
```markdown
## 💡 주요 결정사항

### 결정 1: {결정 제목}
- **결정**: {무엇을 결정했는가}
- **이유**: {왜 그렇게 결정했는가}
- **영향**: {이 결정의 영향은}

### 결정 2: {다음 결정}
...
```

**왜 중요한가?**
- 나중에 "왜 이렇게 했었지?" 질문에 즉시 답변
- 같은 실수 반복 방지

### 7. 생성/변경 파일 목록 (## 🛠️)
```markdown
## 🛠️ 생성된 파일 목록

### Skills (14개)
1. `development/backup/auto-backup.md` ✨
2. `development/documentation/obsidian-auto-doc.md` ✨
...

### 설정 파일
1. `.claude/obsidian-config.json` ✨
...
```

**작성 팁**:
- 상대 경로로 명확히
- 새로 생성된 파일은 ✨ 표시
- 수정된 파일은 ✏️ 표시

### 8. 성과 지표 (## 📊)
```markdown
## 📊 성과 지표

### 토큰 절약
- 세션 시작: 500,000 → 500 토큰 (1000배)
- 문서 검색: 155,000 → 900 토큰 (172배)

### 자동화
- 수동 작업: 100% → 5%
- 자동 백업: 0% → 100%
```

**측정 가능한 것만**:
- Before/After 비교
- 구체적인 숫자
- 백분율 또는 배수

### 9. 관련 문서 링크 (## 🔗)
```markdown
## 🔗 관련 문서

### 생성된 Skills
- [[auto-backup]] - 자동 백업 시스템

### 기술 문서
- [[obsidian-tagging-rules]] - 태그 규칙
```

**링크 규칙**:
- `[[파일명]]` 형식 (확장자 제외)
- 설명 추가: `[[파일명]] - 간단한 설명`
- 카테고리별로 그룹화

### 10. 다음 작업 (## 📝)
```markdown
## 📝 다음 작업

### 즉시 가능
- [x] Skills 구조 재편성
```

- `[ ]` - 미완료

## 🚀 자동 생성 전략

### Claude가 자동으로 생성하는 것
1. **YAML Front Matter** - 메타데이터 자동 추출
2. **태그** - 파일명/내용에서 자동 생성
3. **관련 링크** - 기존 문서 검색하여 자동 연결
4. **요약** - 대화/작업 내용을 100단어로 압축

### 사용자가 제공해야 하는 것
1. **제목** - 핵심 내용 한 문장
2. **중요 결정** - 왜 그렇게 했는지
