🔒 브랜드 페이지 권한 테스트 (프로덕션)

📋 테스트 체크리스트

  • ✅ 심사관으로 로그인되어 있는지 확인
  • ✅ 본인 프로필을 불러올 수 있는지 확인
  • ✅ 본인 브랜드 페이지를 수정할 수 있는지 확인
  • ✅ 다른 심사관의 브랜드 페이지는 수정할 수 없는지 확인

🔐 테스트 1: 현재 세션 확인

현재 로그인된 사용자의 세션 정보를 확인합니다.

👤 테스트 2: 본인 프로필 조회

로그인한 심사관의 프로필을 조회합니다.

✏️ 테스트 3: 본인 브랜드 페이지 수정 (권한 있음)

본인의 브랜드 페이지를 수정할 수 있어야 합니다.

🚫 테스트 4: 다른 심사관 브랜드 페이지 수정 (권한 없음 - 실패해야 정상)

다른 심사관의 ID를 입력하여 수정을 시도합니다. 403 Forbidden 에러가 발생해야 정상입니다.

🌐 테스트 5: 브랜드 편집 페이지 접근

실제 브랜드 편집 페이지로 이동합니다.
