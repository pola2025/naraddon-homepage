# ⚠️ 이 디렉토리는 사용되지 않습니다

**주의: 이 `/src/app` 디렉토리는 현재 프로젝트에서 사용되지 않습니다.**

## 현재 프로젝트 구조

- **`/app`** - 실제 프로덕션에서 사용하는 Next.js 페이지 라우팅
- **`/src/components`** - 컴포넌트
- **`/src/lib`** - 라이브러리 및 유틸리티
- **`/src/styles`** - 스타일 파일
- **`/src/app`** - ❌ **사용되지 않음 (백업/레거시)**

## 왜 사용되지 않나요?

Next.js는 `/app` 또는 `/src/app` 중 하나만 사용합니다.
현재 프로젝트는 `/app`을 메인으로 사용 중입니다.

이 디렉토리는 이전 버전의 백업이거나 테스트 파일입니다.

## 작업 시 주의사항

- **새 페이지 생성**: `/app` 디렉토리에 생성
- **컴포넌트 생성**: `/src/components`에 생성
- **이 디렉토리는 수정하지 마세요**
