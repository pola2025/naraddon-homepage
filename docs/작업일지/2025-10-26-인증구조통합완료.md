### Phase 1: app/auth-options.ts 강화 (10분)
**작업 내용:**
- `app/auth-options.ts`에 MongoDBAdapter 추가
- 기존 네이버 OAuth 설정 100% 보존
- 기존 콜백 로직(signIn, jwt, session) 유지

**변경 사항:**
```typescript
// Before
export const authOptions: NextAuthOptions = {
  providers: [/* 네이버 설정 */],
  callbacks: {/* JWT, session */}
}

// After
import { MongoDBAdapter } from '@next-auth/mongodb-adapter';

export const authOptions: NextAuthOptions = {
  adapter: MongoDBAdapter(clientPromise, {
    databaseName: 'naraddon',
  }),
  providers: [/* 네이버 설정 - 변경 없음 */],
  callbacks: {/* JWT, session - 변경 없음 */}
}
```

**핵심 의도:**
- MongoDBAdapter가 `accounts`, `sessions` 컬렉션 자동 생성
- OAuth 계정 연결 정보 저장으로 OAuthAccountNotLinked 해결
- 네이버 로그인 로직은 한 글자도 건드리지 않음

**결과:**
- ✅ 빌드 성공
- ✅ TypeScript 에러 없음
- ✅ 네이버 OAuth 무손상

**커밋:** `802bb88` - "feat: MongoDBAdapter 추가하여 OAuthAccountNotLinked 에러 해결"

## 🎯 해결된 문제

### 1. OAuthAccountNotLinked 에러
**원인:**
NextAuth가 JWT 전용 전략을 사용하여 accounts 테이블이 없었음

**해결:**
MongoDBAdapter 추가로 accounts, sessions 컬렉션 자동 생성

**예상 결과:**
네이버 로그인 시 OAuth 계정 정보가 DB에 저장되어 에러 해결

### 2. authOptions 파일 분산
**원인:**
5개의 중복 authOptions 파일이 존재하여 설정 불일치

**해결:**
`app/auth-options.ts` 하나로 통합, 나머지 4개 삭제

### 3. Import 경로 혼란
**원인:**
각 API가 다른 경로에서 authOptions를 import

**해결:**
44개 파일 모두 `@/app/auth-options`로 통일

### 4. 브랜드 페이지 편집 버튼
**근본 원인:**
`stats?.examinerId`가 null → 버튼 숨김

**해결 경로:**
MongoDBAdapter → JWT 콜백 정상 작동 → examinerId 세션 저장 → 버튼 표시
