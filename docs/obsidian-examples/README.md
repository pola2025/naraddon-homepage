## 🤖 메타데이터 자동 생성 시스템

### 자동화 Skill
`.claude/skills/automation/metadata-auto-generator.md` Skill이 다음을 자동으로 처리합니다:

#### 자동 생성 항목 (80%)
✅ **프로젝트 식별** (100% 자동)
- 현재 디렉토리에서 프로젝트 자동 감지
- 프로젝트코드 자동 매핑

✅ **기능 모듈 추론** (70% 자동)
- 파일 경로 분석 → 모듈 자동 추론
- `lib/auth/` → "관리자/인증"
- `app/api/policy-news/` → "정책뉴스"

✅ **태그 생성** (100% 자동)
- 3-level 중첩 태그 자동 생성
- 기술 스택 파일 기반 자동 추론
- YAML 태그 + 해시태그 라인 동시 생성

✅ **관계 문서 연결** (50% 자동)
- 최근 7일 관련 문서 자동 검색
- Git 히스토리에서 선행작업 추출
- 대화에서 언급된 문서 자동 링크

✅ **메트릭 계산** (80% 자동)
- 소요시간 대화 기반 자동 계산
- 심각도 키워드 기반 자동 판단
- 영향 범위 파일 분석 자동 추론

#### 사용자 확인 필요 (20%)
❓ **근본원인** - AI 추론값 제시, 사용자 확인
❓ **후속작업** - AI 제안, 사용자 선택
❓ **소요시간** - 자동 계산값 있으나 확인 권장
