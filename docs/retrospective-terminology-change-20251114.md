## 🚧 어려웠던 점

### 1. 전문가/심사관 구분
**문제**: 초기에 모든 "상담"을 "심사"로 변경했다가 피드백 받음
```
사용자: "전문가는 심사 아니고 상담"
```

**해결**:
- 심사관(Examiner) 관련만 "심사" 적용
- 전문가(Expert) 관련은 "상담" 유지
- `app/expert-services/[id]/page.tsx` 되돌림

### 2. 숨겨진 참조 찾기
**문제**: 같은 버튼인데 클래스명으로만 구분되는 경우
```
사용자: "심사관 상세페이지에서
<button class='HeroSection_btnPrimary__TO_30'>
<span>상담 신청하기</span></button> 이 버튼"
```

**해결**:
- CSS Module 클래스명으로 파일 추적
- `HeroSection_btnPrimary` → `examiner-brand/HeroSection.tsx` 특정

### 3. 일관성 있는 번역
**문제**: 같은 의미의 다양한 표현
```
"상담 신청하기"
"무료상담신청"
"무료 상담 시작하기"
"상담 예약하기"
```

**해결**:
- 심사관 관련: "무료심사신청", "심사 신청하기"로 통일
- 컨텍스트에 따라 적절한 표현 선택
